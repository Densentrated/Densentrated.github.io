Dither

Problem

Lots of wallpapers exist, but there are two key issues. Most won't match your screen resolution, and most won't match your color scheme.

Solution

The fix was to lean on an old technique for reducing an image's color palette called dithering. Formally, dithering is the intentional application of noise to data before quantization in order to spread out quantization error — but it's easier to just see it in action. Take an image converted to black and white with a single threshold versus one converted using ordered dithering: the dithered version preserves far more perceived detail using the same two colors.

The same principle extends beyond black and white. By swapping in any target color palette, you can dither an image to match an arbitrary set of colors while keeping the image looking cohesive. Back in the early 2000s, dithering was a common trick for shrinking file sizes. Today, storage isn't the concern — which means you can dither an image and still keep its full resolution, making it a practical tool for wallpaper theming.

I built a CLI tool in Go using its native image library along with a CLI framework to tie everything together. The tool supports creating and saving custom color palettes for reuse. For dithering algorithms, I started with ordered dithering since it was the most straightforward to implement, then added Floyd-Steinberg and Stucki afterward to produce smoother, more natural-looking results.
